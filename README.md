# TRIPLETEN-PROJECTS
Dentro de este repositorio encontrará todos los projectos relacionados al curso de TRIPLETEN para uso educativo
## Descripción

Proyecto de análisis de datos realizado en Python utilizando pandas, matplotlib y seaborn.

## Objetivos

- Limpieza de datos
- Análisis exploratorio (EDA)
- Detección de outliers
- Segmentación de clientes
- Insights de negocio

## Herramientas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
